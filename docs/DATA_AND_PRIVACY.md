# Données et confidentialité

Maintien proposé du comportement existant : notes, matières, descriptions, réglages et photos en stockage privé Android. Données scolaires potentiellement personnelles, notamment dans les photos. Aucun compte, backend, analytics ni publicité.

Export PDF et sauvegarde uniquement vers une destination choisie. Conserver les exclusions de sauvegarde cloud Android et la politique de transfert local documentées dans 1.6.0. Les fichiers exportés restent sous le contrôle de l'utilisateur.

Suppression d'une note : supprimer les pièces jointes devenues orphelines après validation de l'état. Simulation : uniquement en mémoire. Réinitialisation : confirmation explicite et option de sauvegarde ; aucune suppression au chargement en cas d'erreur de décodage.

La maquette emploie uniquement des données fictives ; rien ne lit les notes réelles. Les secrets de signature restent dans le mécanisme existant hors dépôt et hors logs.
