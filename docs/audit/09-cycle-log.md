  - Targeted unit tests for PlusPoints import.
  - Targeted instrumented tests for backup import.
  - Full `release-check` after environment allows Gradle execution.
- Acceptance criteria:

  - Oversized PlusPoints XML is rejected.
  - Backup attachment paths using absolute/traversal syntax are rejected.
  - Unsafe note/attachment ids are rejected before filesystem restore.
  - Existing valid backup and PlusPoints imports remain covered by tests.
- Implementation:
  - PlusPoints import now reads selected XML through a bounded input function before parsing.
  - PlusPoints plist parsing now uses a hardened XML factory with mandatory DOCTYPE rejection and best-effort external entity disabling.
  - Backup import now validates manifest attachment paths against the unpacked `attachments/` root and rejects traversal/absolute paths.
  - Backup import/export now reject unsafe note and attachment ids before using them as path components.
